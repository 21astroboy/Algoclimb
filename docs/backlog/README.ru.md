[English](README.md) · [Русский](README.ru.md) · [Канбан-доска](https://github.com/users/21astroboy/projects/1/views/1)

Здесь сохранены расширенные описания 20 существующих карточек. У каждой указаны проблема,
текущее состояние, место в интерфейсе, сценарий решения, пример до/после, ожидаемый результат,
критерии приёмки, границы, файлы реализации и зависимости. Это план работ, а не заявления о готовых функциях.
Статусы, приоритеты, размеры и итерации остаются в полях доски; обновление описаний их не меняет.
Исходные критерии сохранены и дополнены. Описания сверены с кодом 24 ноября 2026 года.

## Откуда скриншоты

В `images/` — настоящие экраны локального интерфейса с искусственными студентами, наборами и результатами.
Данные VPS, реальные студенты, приватный банк и секреты не использовались. Верхняя плашка поясняет место доработки
и не является частью продукта. `operations-proposal.png` — явно обозначенная схема будущего процесса,
а не готовый экран резервного копирования/выкатки.

Изображение помогает найти место задачи; отсутствие функции устанавливается описанием и кодом, а не одним скриншотом.
В карточках черновиков и мобильности отдельно отмечено, что уже реализовано последними обновлениями.

Повторное получение изображений после установки зависимостей:

```bash
node tools/capture_backlog.cjs
# На macOS можно использовать установленный Chrome:
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' node tools/capture_backlog.cjs
```

Все запросы приложения перехватываются тестовой страницей, настоящие занятия не открываются.
Изображения хранятся в репозитории; карточки доски ссылаются на конкретный коммит, чтобы контекст не менялся случайно.
При дальнейшем уточнении задачи обновляйте файл карточки и её описание в Projects вместе. Рабочий статус ведётся на доске.
