Read session data

GET /api/v1/sessions?limit=50&offset=0
GET /api/v1/sessions/{id}
GET /api/v1/sessions/{id}/results
GET /api/v1/sessions/{id}/answers
GET /api/v1/sessions/{id}/attendance
GET /api/v1/sessions/{id}/events

Authorization: Bearer <api-key>

All responses are JSON. List endpoints accept limit and offset. Expired and revoked keys return HTTP 401.

Older set names are inferred from answered question IDs. Missing historical data is marked unavailable. Practice sessions have no saved database history.
